Open draw.io.



Select Device to save your diagram locally.



Choose Create New Diagram → Blank Diagram.



Name it E-Waste Recycler Finder Class Diagram.



From the shapes panel, enable UML or search for UML Class.



Drag class shapes onto the canvas. Each class has three sections: class name, attributes, and methods.



Create the following classes and connect them using relationship lines.
