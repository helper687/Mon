1. Schedule a Project Plan - E-Waste

Tools required:
- Trello
- Web browser and internet connection

Project: E-Waste Recycler Finder

Objective:
Develop a system that helps users locate nearby e-waste recyclers.

Performance steps:

Step 1: Create a board
1. Open Trello and log in.
2. Click Create → Create board.
3. Enter E-Waste Recycler Finder.
4. Create the board.

Step 2: Create lists
Create four lists:
To Do, In Progress, Review, and Done.

Step 3: Add cards
Create these seven cards:
- Requirement Analysis — Week 1 — Analyst
- UI/UX Design — Week 1 — UI Designer
- Database Design — Week 2 — Backend Developer
- Recycler Location Finder — Week 2 — Developer
- Frontend Development — Week 3 — Frontend Developer
- Testing and Debugging — Week 4 — Tester
- Deployment and Documentation — Week 4 — Project Team

Step 4: Set deadlines
Open each card, click Dates, select a due date, and confirm it.
Choose dates covering four weeks.

Step 5: Add descriptions
Examples:
- Requirement Analysis: Identify system objectives and user requirements.
- Database Design: Design tables for users, recyclers, and locations.
- Recycler Location Finder: Implement nearby facility search.
- Testing and Debugging: Test features and fix errors.

Step 6: Track progress
Move cards through:
To Do → In Progress → Review → Done

Step 7: Verify the board
Check that every task has a deadline and is organized correctly.

1. Open draw.io.
2. Select Device to save the diagram locally.
3. Choose Create New Diagram → Blank Diagram.
4. Name it E-Waste Recycler Finder Class Diagram.
5. Enable UML or search for UML Class.
6. Add class shapes containing class names, attributes, and methods.
7. Connect the classes using relationship lines.

10. Explore Agile Methodology Tools

Aim:
Explore an Agile project management tool and manage project tasks using an Agile workflow.

Tool:
Trello — beginner-friendly and suitable for this practical.

Theory:
Agile develops a project in small steps with continuous feedback and regular improvements. Trello organizes tasks using boards, lists, and cards.

Project 1: E-Waste Recycler Finder

Objective:
Develop a system to find nearby e-waste recyclers.

Steps:
1. Open Trello and log in.
2. Create a board named E-Waste Recycler Finder - Agile.
3. Create lists: Product Backlog, To Do, In Progress, and Done.
4. Add these cards to the Product Backlog:
   - User registration and login — High
   - Search recyclers by location — High
   - View recycler details — High
   - Submit recycling request — Medium
   - Track recycling request — Medium
   - Admin manages recycler listings — Low
5. Select the first three high-priority tasks for the first sprint.
6. Move them to To Do.
7. Move a task to In Progress when work begins.
8. Move it to Done after completing and checking it.

Project 2: Mental Health Management System

   - User registration and login — High
   - Record and view mood history — High

   - Access mental health resources — Medium

   - Admin manages users and resources — Low
4. Select the first three high-priority tasks for the first sprint.
